# Project Goal

AI Workstation Installer

A production-quality installer for Ubuntu 24.04.

Supported applications:

- Cursor
- Devin
- Antigravity IDE

Commands:

- aiws install
- aiws update
- aiws uninstall
- aiws doctor
- aiws report

Design principles:

- Simple
- Modular
- Safe
- Recoverable
- Well tested

Avoid unnecessary abstraction.

Prefer simplicity over extensibility for version 1.
